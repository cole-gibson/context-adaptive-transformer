# context-adaptive-transformer

## Repository Structure

- `base/simple_gpt.py`  
  Main model implementation.

- `base/estimators/markov_model_ar.py`  
  Optimal predictor classes.

- `base/tasks/markov_model.py`  
  Sequence generation code.

- `base/trainer.py`  
  Primary training script.

- `pd/`  
  Analysis scripts for the phase diagram.

- `predictor_scalings/`
  For generating supplementary figure showing predictor scalings with K and N.
